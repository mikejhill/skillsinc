# 0015: SkillSinc brand identity

Date: 2026-10-24

Status: Proposed for local design review

## Context

SkillSinc has a text README heading but no consistent visual identity. It
manages one customization library across multiple AI coding harnesses.

## Decision

Add a continuous S route in mint and periwinkle on an ink tile, with outlined
light and dark wordmarks. Keep editable SVG masters, transparent PNG exports,
and usage guidance together in `docs/brand/`. Apply the theme-aware lockup to
the README. This is a documentation and identity change; the CLI stays text.

## Consequences

Small icons use a broad, simple silhouette. Outlined lettering renders
consistently without fonts. SVG and pixel exports must be updated together.
